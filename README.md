# 折痕 · 隐墨

在 DeepSeek Harness 的对话中，收起暂时不读的段落，轻掩暂时不想看的字句。

**实验版本 0.12.3 · MIT · 非官方社区插件**

面向 DSH 0.2.0-rc.2 的 desktop / web profile。依赖宿主的 DOM 结构，尚未完成真实 DSH / Electron 的发布验收；宿主升级可能需要适配。本项目不隶属于 DeepSeek。

## 两种阅读操作

| | 折痕 | 隐墨 |
|---|---|---|
| 用途 | 收起阅读区域、减少占位 | 遮住字句、保留占位 |
| 创建 | 点击悬浮鲸鱼，再纵向拖过正文 | 普通鼠标选中文字，再点击附近的“隐墨” |
| 范围 | 正文整行、代码逻辑行、列表条目、表格行 | 精确到所选文字 |
| 切换 | 点击折痕展开或收起 | 点击色带揭开或遮住 |
| 单独移除 | Alt 点击，或聚焦后按 Delete | Alt 点击，或聚焦后按 Delete |

也可用 Alt + 左键拖动或右键拖动创建折痕。聚焦折痕或隐墨后，Enter / 空格切换状态；Esc 取消选择。右键点击悬浮鲸鱼恢复当前会话的全部折痕与隐墨。

表格跨行合并单元格可能使范围扩大到整张表，拖动预览会显示实际范围。窗口变窄后仍保存原先选定的文字，不按新的视觉行号重新选择。折痕内可以包含隐墨；不支持嵌套折痕或重叠隐墨。

## 样式

折痕使用细折线、轻阴影与透明标题。展开区域默认使用 `#3b82f6`、4% 浓淡；隐墨默认 10%。悬停鲸鱼后点击设置钮，或 Alt 点击鲸鱼，可调整颜色、浓淡、左右及上下外扩、圆角。设置即时保存，恢复默认只影响外观。

## 安装和更新

插件是免构建的 DSH 组合包，不是浏览器扩展，也不是 DeepSeek 官网脚本。

1. 解压源码包，保留完整的 `dsh-crease` 目录。
2. 在支持本地组合包的 DSH 插件管理器中，以该目录的**绝对路径**安装并启用。包已声明 `dsh.bundle.patch`；由宿主应用 `cordis.patch.yml`。不同版本的界面可能不同，参见[上游插件管理说明](https://github.com/deepseek-ai/deepseek-harness/blob/c1b47e41fcd54d20a0f061df28683bfc29ee24e5/packages/boot/plugin-manager/README.zh.md)。
3. 完全退出 DSH（含托盘）后重启。在开发者工具中检查 `window.__dshCrease.version`，应为 `0.12.3`。

已有手动安装或软链的用户：退出 DSH 后更新实际插件目录，保留原有加载配置。必须同步 `package.json` 与对应客户端入口。安装运行无需 `npm install`；开发测试才需要依赖。首次安装流程尚待真实 DSH 验证，若安装器拒绝本地路径，请记录宿主版本和错误反馈。

## 开发

使用 Node.js 24：

```sh
npm ci --ignore-scripts
npm test
```

客户端源码即 `client-v0.12.3-paper.js`，无需构建。`lib/index.js` 是空的 Node 端入口。`private: true` 仅防止误发布到 npm，不影响 MIT 开源和本地安装。

目前有 73 项 DOM、模拟几何和事件回归测试。它们不验证真实浏览器排版；用 Chrome / Edge 打开 `tests/preview.html` 可进行手工浏览器检查。CI 配置随包提供，尚未在远程仓库运行。

## 数据与边界

插件不发起网络请求，不改写宿主保存的对话源数据。它会在当前站点的 `localStorage`（`dsh.crease.v3`）保存样式、会话标识、选中文字及前后文，用于重新定位。**隐墨是视觉遮盖，不是安全脱敏**，原文仍可被页面脚本、开发者工具或辅助技术读取。

卸载插件不等于清除浏览器存储。需要清除插件记录时，可在该站点开发者工具中删除上述键；操作会清除所有会话的插件记录和样式。

流式生成和可编辑区域不处理。复杂公式、多栏排版、封闭 Shadow DOM、iframe 和宿主重渲染仍可能存在适配问题。锚点无法可靠匹配时保留原文。

诊断入口为 `window.__dshCrease.diag()`；其他入口包括 `folds()`、`inks()`、`getStyle()`、`openSettings()`、`restoreAll()`。诊断和记录可能含对话文字，提交问题前请脱敏，优先使用虚构文本复现。
